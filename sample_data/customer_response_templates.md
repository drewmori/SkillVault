# Northstar Cloud Customer Response Templates

## Investigation in progress

Use this structure:

1. Acknowledge the specific customer impact.
2. State only confirmed facts.
3. Explain the next investigation step.
4. Give a named owner and a specific update time.
5. Avoid unsupported promises such as “this will never happen again.”

## Feature request

Clarify the desired outcome, check supported configuration options, capture the business impact, and explain that roadmap decisions require product review.
