# Northstar Cloud Support Triage Playbook

## First response

1. Capture the customer, tenant, product area, timestamps, request IDs, and exact impact.
2. Reproduce the issue with the smallest safe example.
3. Search the incident and known-issue history before changing anything.
4. Tell the customer what is confirmed, what is being investigated, and when the next update will arrive.

## Priority signals

Escalate priority when the issue affects many customers, blocks a critical workflow, involves security or data integrity, has no workaround, or follows a production deployment.

## Evidence standard

Do not promise a root cause from a symptom alone. Include timestamps, tenant ID, request ID, environment, reproduction steps, expected behavior, actual behavior, logs, and screenshots when available.
