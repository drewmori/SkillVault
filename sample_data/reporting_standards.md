# Northstar Cloud Reporting Standards

## Weekly client health report

Use this order:

1. Account status and one-line summary
2. Wins and progress
3. Risks and unresolved issues
4. Dated usage and support metrics
5. Open actions with one owner and due date each
6. Decisions or asks

Define each metric, date range, timezone, and source system. If two reports disagree, freeze the conflicting inputs and request data-owner review instead of choosing the number that supports a preferred story.
