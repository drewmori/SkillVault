# Northstar Cloud Engineering Handoff Template

Every handoff should include:

- Short problem statement
- Exact reproduction steps
- Expected versus actual behavior
- Tenant, environment, version, and timestamps
- Request IDs, logs, screenshots, or video with secrets removed
- Number and type of affected customers
- Workaround status
- Proposed priority and why
- One clear question for engineering

For code changes, include a failing test or smallest reproducer before proposing a fix. Prefer a narrow, reversible change and add a regression test.
